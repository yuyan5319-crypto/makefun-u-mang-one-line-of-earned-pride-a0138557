One line of text (1–240 characters) that gives the judge a quiet, earned
moment of pride: a seventy-two-year-old grandfather, after two winters of
tracing letters at the kitchen table, reads a pharmacy label aloud to
himself — and never once looks up for help.

## Run it

```sh
node main.ts
```

This writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`
when the variable is not set).
